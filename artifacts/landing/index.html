How to install

  1. Tap Download APK and wait for the file Lucky777.apk to finish downloading.
  2. Open the file from your notifications or the Downloads folder.
  3. If Android says "For your security, your phone is not allowed to install unknown apps from this source", tap Settings and switch on Allow from this source, then go back and tap Install.
  4. If Play Protect shows a warning, tap More details → Install anyway. The app is not on the Play Store, so this warning is normal.
  5. Open Lucky777, create your account and you're ready.
